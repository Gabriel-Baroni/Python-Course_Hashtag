## 🇧🇷 Versão em Português

Nesta seção, detalho o que foi desenvolvido em cada uma das etapas do treinamento:

### AULA 01: Automação de Tarefas e Bots 
* **O Projeto:** Criação de um bot de RPA para automatizar o cadastro de produtos em um sistema web.
* **O que fiz:** Utilizei a biblioteca `pyautogui` para controlar o mouse e o teclado, e o `pandas` para ler a base de dados dos produtos. O script realiza o login e cadastra cada item automaticamente.

### AULA 02: Análise de Dados 
* **O Projeto:** Análise de uma base com mais de 50 mil clientes para identificar os principais motivos de cancelamento (*churn*).
* **O que fiz:** Usei `pandas` para limpeza e tratamento de dados e a biblioteca `plotly` para criar gráficos interativos, permitindo identificar que clientes com contrato mensal e muitas ligações ao call center tinham maior taxa de cancelamento.

### AULA 03: Previsão com Machine Learning
* **O Projeto:** Desenvolvimento de uma IA para classificar o Score de Crédito de clientes (Bom, Médio ou Ruim).
* **O que fiz:** Apliquei o `scikit-learn` para treinar modelos de **Random Forest** e **KNN**. O objetivo foi prever o perfil de novos clientes com base em dados históricos, atingindo uma acurácia de aproximadamente 82%.

### AULA 04: Chat em Tempo Real 
* **O Projeto:** Desenvolvimento de um chat ao vivo.
* **O que fiz:** Utilizei **Flask** e **Flask-SocketIO** para permitir a troca de mensagens instantâneas. Implementei a lógica de *broadcast*, onde uma mensagem enviada por um usuário é transmitida em tempo real para todos os outros conectados.

## 🇺🇸 English Version

In this section, I detail what was developed in each stage of the training:

### LESSON 01: Task Automation & Bots (Python PowerUp)
* **The Project:** Building an RPA bot to automate product registration in a web system.
* **What I did:** Used the `pyautogui` library to control mouse and keyboard, and `pandas` to read the product database. The script performs login and registers each item automatically.

### LESSON 02: Data Analysis (Python Insights)
* **The Project:** Analyzing a database of over 50,000 customers to identify the main reasons for customer churn.
* **What I did:** Utilized `pandas` for data cleaning and processing, and the `plotly` library to create interactive charts, identifying that monthly contract customers and high call center usage were key churn drivers.

### LESSON 03: Forecasting with Machine Learning
* **The Project:** Developing an AI to classify customer Credit Scores (Good, Standard, or Poor).
* **What I did:** Applied `scikit-learn` to train **Random Forest** and **KNN** models. The goal was to predict new customers' profiles based on historical data, achieving an accuracy of approximately 82%.

### LESSON 04: Real-Time Chat 
* **The Project:** Live chat application development.
* **What I did:** Used **Flask** and **Flask-SocketIO** to enable instant messaging. I implemented *broadcast* logic, ensuring that a message sent by one user is transmitted in real-time to all connected peers.
